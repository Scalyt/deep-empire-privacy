Политика конфиденциальности

Настоящая политика описывает обработку данных в игре Deep Empire: Royal Edition («Игра»), разработчик — Linaks Lab («мы»). Контакт для вопросов о конфиденциальности: linakslab@gmail.com.

1. Данные и сохранения

Игра предназначена для игрового процесса без обязательной регистрации. При условии, что текущая версия сохраняет прогресс только на устройстве, игровые сохранения и настройки хранятся локально и не передаются разработчику. Если в установленной версии присутствуют аналитика, облачные функции, отчёты об ошибках или другие сетевые SDK, этот раздел должен быть дополнен до публикации.

2. Реклама и покупки

На дату обновления политики реклама Google AdMob и покупки через Google Play Billing только планируются и не заявляются как действующие функции. До их запуска мы обновим политику, чтобы раскрыть фактическую обработку данных соответствующими сервисами.

3. Передача и защита

Мы не заявляем о передаче персональных данных третьим лицам в рамках базового офлайн-процесса игры. Это утверждение применимо только если фактическая сборка не содержит сетевых инструментов сбора данных. Данные, сохраняемые на устройстве, защищаются средствами операционной системы; безопасность самого устройства также зависит от его настроек.

4. Хранение и удаление

Локальные игровые данные могут сохраняться до удаления данных приложения или его удаления с устройства. Пользователь может удалить локальные данные через настройки Android. По вопросам о данных, которые могут обрабатываться разработчиком, обращайтесь по указанному адресу.

5. Дети и изменения

Мы стремимся минимизировать обработку данных. Перед выпуском функций для детей, рекламы, покупок или аккаунтов мы проверим соответствующие требования и обновим политику. Изменения публикуются на этой странице с обновлённой датой.

Privacy Policy

This policy describes data handling in Deep Empire: Royal Edition (the “Game”), developed by Linaks Lab (“we”). Privacy contact: linakslab@gmail.com.

1. Data and game saves

The Game is intended to be playable without mandatory account registration. Provided the current release stores progress only on the device, game saves and settings remain local and are not transmitted to the developer. If the released build contains analytics, cloud features, crash reporting, or other network SDKs, this section must be updated before publication.

2. Advertising and purchases

As of this policy's update, Google AdMob advertising and Google Play Billing purchases are planned features, not represented as currently active. Before enabling either, we will update this policy to describe the actual data processing performed by the relevant services.

3. Sharing and security

We do not represent personal data as being shared with third parties as part of basic offline gameplay. This statement applies only if the actual release build does not contain network-based data collection tools. Data stored on the device benefits from operating-system safeguards; device security also depends on user settings.

4. Retention and deletion

Local game data may remain until the user clears the app's data or uninstalls it. Users can remove local data through Android settings. For questions about any data that may be processed by the developer, contact the address above.

5. Children and changes

We aim to minimize data processing. Before launching features involving children, advertising, purchases, or accounts, we will review applicable requirements and update this policy. Changes will be published on this page with a revised date.
